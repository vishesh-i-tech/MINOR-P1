# Student Retention Intelligence Platform

Subtitle:
An Explainable AI-Based Early Warning, Counseling and Intervention System for Student Retention.

## Core Idea

We are building an AI-based system that identifies students who may be at risk of dropping out BEFORE dropout actually happens and helps authorized counselors take appropriate action.

The system analyzes available student data such as:

- Attendance
- Grades / academic performance
- Assignment submissions
- Engagement/activity data
- Other justified student-related features available in the dataset

It generates a dropout-risk score.

Example:

Student → 78% High Risk

But the system should NOT stop there.

It should also explain WHY the student has a high risk.

Example:

- Low attendance → major contributor
- Declining grades → significant contributor
- Missed assignments → contributor

We plan to use Explainable AI, especially SHAP, to generate these explanations.

Then the system should recommend a suitable intervention category based on the identified risk drivers.

Example:

Low attendance
→ Attendance counseling

Academic decline
→ Academic support / mentoring

Financial-related issue
→ Relevant institutional support information

The counselor remains the human decision-maker. The AI supports the counselor; it does not automatically decide the student's future.

After the counselor takes action, the intervention is recorded.

Later, when new student data becomes available, the system recalculates the student's risk.

Example:

78% → Intervention → 52% → Follow-up → 31%

This creates a longitudinal risk trajectory.

The purpose is to observe whether the student's situation improved after intervention.

Important:
A decrease in risk after intervention should be treated as an observed outcome/association, NOT automatically claimed as proof that the intervention caused the improvement.

# MACHINE LEARNING

For ML, we are considering:

- Logistic Regression as baseline
- Random Forest
- XGBoost
- LightGBM

Do not automatically decide which model is final.

We should compare models using appropriate evaluation metrics.

Potential metrics:

- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC
- PR-AUC where appropriate
- Calibration if we present probabilities

Accuracy alone should NOT be treated as the main success metric, especially if the classes are imbalanced.

We also need to avoid data leakage.

The exact final model will be selected based on experimentation and evaluation.

# EXPLAINABLE AI

We plan to use SHAP.

Purpose:

The system should explain why a particular student received a particular prediction.

Example:

Risk = 78%

Contributors:

Attendance decline → increases predicted risk
Missed assignments → increases predicted risk
Academic decline → increases predicted risk

Important:

SHAP contributors are NOT guaranteed causal reasons.

Use terminology like:

"Important model contributors"

rather than:

"These are definitely the reasons the student will drop out."
